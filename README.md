# JD 맞춤 지원서 초안기

채용공고(회사·도메인)와 내 프로젝트 정보를 넣으면, 적합 직무 추천 → 자격요건 체크 → 추천 프로젝트 → 보완 제안 → 이력서/자기소개서용 문구 초안까지 도와주는 웹 서비스입니다.

## 파일 구조

- `/`: index.html (단일 페이지 프론트)
- `/api/analyze.js`: Vercel Node 서버리스 함수 (공고 분석, 프로젝트 정보 확보, 체크리스트, 추천, 보완 제안, 문구 초안)

## 입력

- 공고 URL 또는 공고 텍스트
- 회사/관심사(직무 추천이 필요할 때)
- 내 프로젝트 정보(GitHub·노션·구글문서 링크 또는 프로젝트 설명 텍스트)
- 출력 형태 선택: 이력서용 / 자기소개서용 / 둘 다

## 출력

- 직무 후보(필요 시)
- 공고 요약
- 자격요건 대비 체크(요건/상태/근거)
- 추천 프로젝트(상위 2~3개)
- 부족한 부분 보완 제안
- 이력서용/자기소개서용 문구 초안

## 기술 노트

- 프론트: 단일 페이지(index.html)
- 백엔드: Vercel Node 서버리스 함수
- GitHub 레포 정보는 GitHub REST API(공개 API, 가능하면 토큰)로 가져옴
- 공고 URL 본문 추출은 /api에서 직접 수행하고, 실패 시 텍스트 입력으로 fallback

## 환경변수(선택)

- GITHUB_TOKEN: GitHub API 호출 안정성용. 없어도 동작 가능하지만 rate limit 대응 시 권장.
- 키 값은 코드/응답에 노출하지 않음.
