JD 맞춤 지원서 초안기

채용공고(회사·도메인)와 내 프로젝트 정보를 넣으면, 적합 직무 추천 → 자격요건 체크 → 추천 프로젝트 → 보완 제안 → 이력서/자기소개서용 문구 초안까지 도와줍니다.

공고 URL 또는 공고 텍스트를 입력하세요. 둘 다 가능합니다. URL이 안 되면 공고 텍스트를 붙여넣어 주세요.
예: 토스뱅크(핀테크), 신한은행(금융)처럼 회사나 관심 분야를 적어 주세요.
내 프로젝트 정보(GitHub·노션·구글문서 링크 또는 프로젝트 설명 텍스트)도 함께 알려 주세요.
GitHub 프로필·레포 링크, 노션 링크, 구글 문서 링크, 또는 프로젝트 설명 텍스트를 입력하세요. 여러 개여도 됩니다.

연결 계정(내 프로필) — 지금은 로그인 후 사용

지금은 로그인 기능을 아직 넣지 않았습니다. 이 섹션은 로그인 이후에 사용하며, 내 분석 소스가 될 연결 계정(GitHub·블로그·문서 등)을 저장해 두는 자리입니다. 지금은 입력을 직접 넣는 방식으로 분석합니다.
이 결과는 그대로 제출 가능한 완성문이 아니라, 사용자가 다듬을 초안입니다. 근거 없는 추천·허위 스펙은 만들지 않습니다. 공고 정보가 부족하면 "공고에 명시된 정보가 부족하다"고 표시합니다. 수상 여부가 불명확하면 단정하지 않고 확인 필요로 표시합니다.
